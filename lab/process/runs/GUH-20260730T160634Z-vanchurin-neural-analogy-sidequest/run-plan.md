# Vanchurin neural-network analogy side quest

## Authorization and bounded target

Joe asked for Vitaly Vanchurin's *Theories of Everything* transcript and
papers to be read by ten divergent neural-network/network specialists, with
each proposed analogy to the present GU construction graded by how closely it
matches the mathematics.

This is not a new substrate candidate and not another search for whether GU
needs a source action or external datum. The comparison target is the frozen
N1/N3 bulk-plus-defect source-action and P1/P2/P3 datum packet already written
in this repository. The side quest may:

1. identify maps that sharpen an unfinished N3 interface;
2. propose a parameter-free construction or hostile test;
3. identify false friends before they contaminate later construction; and
4. rank those returns by information gain.

It may not replace the GU construction with a neural network, infer a
generation count from layers or neuron number, treat a loss as automatically
identical to an action, or promote an analogy into a claim.

## Fidelity score

Each axis is an integer from 0 to 5:

- \(O\): object/carrier fidelity;
- \(D\): dynamics, equation, or variational-operation fidelity;
- \(S\): symmetry, variance, grading, and type fidelity;
- \(C\): consequence/observable fidelity.

The aggregate is

\[
F=\min\left(\frac{O+D+S+C}{4},\ \min(O,D,S,C)+1\right).
\]

The second term prevents one matching feature from hiding a failed carrier,
symmetry, or consequence.

Labels:

- `4.50--5.00`: literal/near-isomorphic;
- `3.50--4.49`: strong structural correspondence;
- `2.50--3.49`: partial structural correspondence;
- `1.50--2.49`: heuristic only;
- `0.00--1.49`: false friend.

Hard caps:

- no explicit relating map: \(F\leq3\);
- an unclosed Layer-0 homonym: \(F\leq2\);
- target-coded parameter or held-out answer: constructive value zero;
- mismatched consequence: never “literal”;
- a positive-definite optimizer metric cannot silently become GU's
  indefinite Krein pairing.

## Controls and kill conditions

- Positive control: an identity map between a frozen equation and itself must
  score in the literal band.
- Structural control: a covector-to-vector musical map with different metrics
  must remain below literal.
- Homonym plant: rename dataset data as “external datum”; Layer 0 must reject
  the identification.
- Count plant: set a network to three layers; the grader must reject a
  generation/index consequence.
- Symmetry plant: replace an equivariant intertwiner by a dimension-matched
  arbitrary matrix; the symmetry score must fall.
- Positivity plant: substitute a positive covariance metric for the Krein
  form; the type/symmetry control must fire.
- Parameter plant: insert a desired P3 value into a loss or architecture; its
  constructive value must be zero.
- Line-typing plant: identify P3's auxiliary relative line with a physical
  P1 determinant/Pfaffian line without a canonical comparison; reject it.
- Shared-datum plant: split the one \(L_\sigma\) line into independent P1
  and P2 datum pieces; reject it.
- Provenance control: interview rhetoric cannot outrank the equations and
  caveats in the papers.

Kill any proposed import that requires identifying two carriers solely by
dimension, converts a density-dual current without a declared musical map,
erases \(K/C\) separation, or imports a held-out value.
