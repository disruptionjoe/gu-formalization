# Krein sea-flux discriminator

## Objective

Test the smallest type-correct contact between:

1. Finster's causal-fermion-system Dirac-sea baryogenesis mechanism;
2. GU's W186/W216 like-signed real-spectrum branch and opposite-signed
   exceptional/pathological branch; and
3. the unresolved GU source-action selector.

The run must decide whether this contact supplies a branch selector, only an
admissibility boundary, or no well-typed bridge at all.

- `STANDARD`: finite-dimensional spectral calculus, Hilbert self-adjointness,
  projection-valued measures, similarity invariance of spectrum, and
  quasi-Hermitian/Krein spectral facts.
- `PROJECT_NATIVE`: W186's reservoir-sign fork and W216's good/pathological
  Bogoliubov blocks.

  metric and ordinary spectral measure actually exist.

No result may silently promote the conditional posit to a GU identification.

## Predeclared discriminators

1. Does each GU branch admit a positive-definite metric in which its generator
   is self-adjoint?
2. Is the ordinary Hilbert spectral projector required by the Finster rate
   defined on both branches?
3. Does an orientation/sign flip reverse a rate within one common typed
   domain, or does the pathological branch leave that domain?
4. Is there a common map from both branches to causal-fermion-system universal
   measures under one frozen variational problem, sufficient to compare causal
   action values?
5. Does the finite calculation produce anything stronger than a standard
   spectral-flow/avoided-crossing absorber?

## Controls and kill conditions

- Positive control: the W216 good block is Hermitian, real-spectrum and admits
  ordinary spectral projectors.
- Hostile control: the W216 pathological block is Krein-self-adjoint but
  develops complex eigenvalues for `|xi| < Delta`.
- Exact obstruction: a matrix with nonreal spectrum cannot be self-adjoint in
  any positive-definite inner product.
- Static control: a time-independent regularization operator gives zero sea
  flux.
- Literature control: the Minkowski-space first-order contribution vanishes;
  the first generally nonzero term is second order and depends on the supplied
  regularization dynamics.
- Stop as `ADMISSIBILITY_ONLY` if the Finster functional is defined only on
  the good branch but no common causal-action comparison exists.
- Stop as `INCOMPLETE_CONTRACT` if a common branch-to-measure construction
  would have to be invented or target-coded.
- Advance only if one frozen, non-target-coded CFS variational problem both
  admits the two branches and ranks them.
