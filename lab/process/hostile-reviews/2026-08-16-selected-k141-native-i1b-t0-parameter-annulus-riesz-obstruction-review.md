# Hostile review: selected-K141 parameter-annulus Riesz obstruction

## Strongest overclaim attack

Failure of native Riesz calculus to isolate the null radical does not erase
the compact parameter family. On `13 <= |mu| <= 14`, the distortion block is
uniformly invertible and the action-derived graph idempotent is smooth and
bounded. K141 may not say that no band-limited effective elimination exists.

The licensed negative conclusion is narrower: the graph projector has a
ten-dimensional metric base, while the characteristic object is a
nine-dimensional radical followed by a four-dimensional gauge quotient. The
first does not canonically select the latter two.

## Strongest contrary construction

Choose any smooth transverse tensor `u(n)` with `ell_n(u)=1`. Then
`Q_u=I-u ell_n` is a smooth rank-nine projector onto the radical, and a further
gauge slice could represent the five quotient classes. This constructs a
candidate effective connection on a local patch.

It is not action-owned. Different transverse choices give different
representatives and connection terms, and the current action supplies neither
`u` nor the gauge slice. K141 correctly leaves this as an explicit added datum
rather than calling it a Riesz projector.

## Spectral and covariance attack

The nonzero rank-one Schur form might look spectrally separated before an
index is raised. Riesz calculus applies to an endomorphism, not a bilinear
form. Raising with the native DeWitt structure gives a square-zero rank-one
map because `n` is null. Its only eigenvalue is zero; the generalized zero
space is all ten dimensions. The contour projector is therefore `I_10`.

Using an auxiliary Euclidean coefficient metric would make a nonzero
eigenvalue and an orthogonal radical projector, but that metric is basis-
dependent and not the action's Lorentz/DeWitt owner. It cannot support the
claimed covariant five-class operator.

## Weakest reproducibility seam

The annulus proof relies on the completeness of K134's twenty-seven shell
values. K141 replays K140, which replays the K135/K134 packet, and checks the
exact endpoint gap. A change to the selected Shiab, Hodge mass, normalized
covector convention or shell inventory invalidates the band and requires full
replay.

The Riesz obstruction uses a ten-dimensional rational DeWitt calculation at
one null covector and Lorentz covariance from K138. The probe plants a
non-null covector control, for which the square-zero identity must fail.

## Verdict

Pass at the stated ceiling. K141 preserves a valid uniformly bounded compact
graph family, but proves that the native null Schur endomorphism has no
spectral gap capable of selecting its ordinary radical. A five-class
Green/subprincipal matrix still requires an action-owned quotient connection,
gauge slice or boundary owner; it is undefined rather than zero.
