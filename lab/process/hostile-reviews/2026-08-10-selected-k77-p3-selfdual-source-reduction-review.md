# Hostile review: P3 self-dual source reduction

## Verdict

`CURRENT_ACTION_REVIVAL_FALSIFIED__PROJECTED_REPLACEMENT_REMAINS_NEW_CONSTRUCTION`.

The exact current family preserves the chiral split but has rank-three
curvature in each `su(2)` ideal.  For nonzero amplitude it is not a connection
on either one-factor reduction.  Restricting the action before variation is a
valid new construction; projecting the old solution is not.

## Three charges

### 1. Where does the summary outrun the artifact?

“`D_B P_sd=0` supplies the self-dual reduction” outruns the algebra.  Every
Spin(4) bivector in the current curvature commutes with chirality, including
the unwanted anti-self-dual factor.  Conversely, “all self-dual source actions
are dead” also outruns the artifact: only the existing unreduced action family
was tested.

### 2. Where is rigor defending a superseded or mistyped object?

The predecessor's nonzero chiral trace can tempt a verifier to keep hardening
the current family.  That trace belongs to a one-factor projected field space,
whereas the current action was varied on the full parent and produces both
factors.  More exact work on the same full-family trace would defend the wrong
configuration space.

The other trap is treating the auxiliary P3 BPST bundle as the tangential
`SU(2)+` source subbundle because both use the name `SU(2)`.  No bundle map or
connection-preserving diagonal has been constructed.

### 3. If this stands, what else changes?

- v0.145 direct native-pairing kill: **survives**.
- v0.145 self-dual current-action revival: **dissolved**.
- general fixed-characteristic amplitude theorem: **survives**.
- projected restricted-action replacement: **needs-recheck** after an explicit
  principal-bundle diagonal and full Euler recomputation.
- `LT-GR1`, `LT-GR2b`, `LT-GR2c`, `LT-GR2d`, `LT-GR6`: **needs-recheck** in
  distance only; verdicts do not move.
- P1/P2/P3 assignments, residue, quotients and canon verdicts: **survive
  unchanged**.

## Required lenses

- **Layer-0 semantics:** passes. Split preservation, factor reduction,
  auxiliary BPST data and source connection are separate.
- **Prior art:** passes. The P3 packet, v0.145, and tangential-frame prior art
  are cited. No novelty claim is made for Spin(4) decomposition.
- **Clifford/representation:** passes. Both ideals have exact rank three.
- **Principal-bundle geometry:** passes at local obstruction grade. Curvature
  outside the reduced Lie algebra forbids the current nonzero reduction.
- **Chern--Weil:** passes. Factor pairings are nonzero and opposite.
- **Variational:** passes with an open replacement. Restriction-before-
  variation is typed but the GU Euler bank is uncomputed.
- **Symplectic/BV--BFV:** passes with an open burden. No quotient, domain or
  physical sector is inferred.
- **Source:** source is silent on the P3 diagonal/restricted action and directs
  self-duality toward the Einsteinian/tangential reading.

## Dissent

One dissent says the framed cycle canonically identifies the BPST bundle with
the source `SU(2)+` factor.  A framing identifies tangent directions; it does
not identify an independently supplied Hopf bundle and connection with a
subbundle of the source parent.  The dissent becomes viable only after it
writes the missing principal-bundle morphism and checks its characteristic
class and connection.

No ledger verdict or canon change is authorized.
