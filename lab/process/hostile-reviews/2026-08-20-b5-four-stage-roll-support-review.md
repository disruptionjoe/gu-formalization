# Hostile review: B5 four-stage roll-support gate

## Strongest overclaim

The result must not be summarized as "no B5 four-stage differential exists."
The probe constructs a positive exact acyclic coarse differential with all
eight cochain-eligible blocks live and normalized `q=1`. The obstruction is
only to identifying the current **full-nine-block** matrix with the fold of a
**strict stage-preserving** `0 -> 1 -> 13 -> 14` differential.

The artifact was narrowed accordingly. It does not construct or exclude the
full-rank maps, filtered graph embeddings, a nonlinear BV master action, or a
separate Euler/Dirac completion.

## Strongest contrary construction

A filtered graph embedding may mix low/high and field/antifield stages before
projection. Such a map could generate an apparent `S -> S` block after
compression. The 2026-07-29 first write explicitly named this possibility,
and the current gate does not test it because no repository-owned graph map
exists. This remains the strongest contrary route and is the first returned
owner.

A second contrary route is to keep the strict differential eight-block and
place `a D_S` in a separate quadratic Euler operator. That changes which
object the five-field packet normalizes and requires an explicit contract
repair before coefficient work resumes.

## Weakest reproducibility or propagation seam

The support theorem is coarse: it uses the declared stage decomposition and
stage-preserving rolls, not a 1920-dimensional irrep-level differential. The
exact positive control is `1 -> 2 -> 2 -> 1`, while the full complex would
need ranks `(128,1664,128)`. The artifact states this ceiling and does not call
the control a full construction.

Propagation must preserve two facts together: `SS` is structurally absent for
the strict fold, and acyclic eight-block controls exist. Dropping either fact
would turn a scoped eligibility result into a false no-go or a vacuous type
complaint. Current-state and contributor surfaces were updated with both.

## Review disposition

Accepted at exact formal compact-core/coarse multiplicity grade with the claim
ceiling above. The five-field packet remains fail-closed; no canon or GU
verdict moves.
