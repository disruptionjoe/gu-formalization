# Hostile review: relative-boundary/P3 real-KO interface

## Pre-review

- **Fork assumed:** selected real K77 action parent conditionally; no claim that
  K77 inherits the old K95 right-`H` comparator.
- **Search space:** the integer class map and exact normalizations can be
  decided wholesale; the analytic K77 operator/domain/index and count cannot.
- **New un-owned object:** no new datum; the missing physical K77 Fredholm
  realization is an unbuilt output object.
- **What dies:** the claim that boundary winding and P3 lack a typed class map;
  not the normal/tangential connection obstruction or count problem.

## Required lenses

**Layer-0 semantics:** Boundary component, clutching degree, input `KO` class,
connection, Fredholm index and physical count are six different objects. The
result survives only because the report refuses to collapse them.

**Prior art:** The original P3 packet already constructs `H_n`, the collapse
`nu`, the relative class and right-`H` K95 comparator, and explicitly denies an
index or count. The new delta is the typed composition from v0.153's observed
boundary integer plus the exact K77/K95 port and surplus fence. The topology
itself is not new.

**Analytic/index:** A relative class and boundary trivialization do not define a
closed Fredholm operator. No K77 domain, index or count readout is present.

**Symplectic/BV--BFV:** The collapse gives relative support, not a reduced
boundary phase space, presymplectic quotient or BFV charge. No boundary
admissibility result is counted twice as a fit equation.

**KO/Clifford:** A real `KO` twist is compatible with a real K77 bundle, but the
old quaternionic commutant is not. Two `U(32,32)` complex halves retain central
idempotents and do not automatically supply one right-`H` module.

## Charge 1: where the summary outruns the artifact

"The P3 bridge is built" is too broad. What is built is the
boundary-winding-to-relative-`KO` **input twist map**. Calling it an index or
generation bridge would contradict both the packet's explicit fence and the
absence of an analytic K77 realization.

Likewise, using the same integer in two functorial targets does not create a
second independent physics equation. The strict surplus remains zero.

## Charge 2: where rigor could defend a superseded or mistyped object

Porting the original right-`H` `E20_DW` comparator unchanged would defend the
superseded K95 carrier while claiming a K77 result. Complexifying K77 or
writing it as two `U(32,32)` halves does not repair the real Morita mismatch.

The previously proved normal-versus-tangential support obstruction also must
not be used to kill the class map: equality of connections is unnecessary for
one integer to feed two prescribed constructions. It still kills any claim
that the two connections themselves have been identified.

## Charge 3: what else changes if this stands

- typed boundary-winding-to-P3 relative-`KO` map: **survives / built**;
- exact `c2` and fundamental/adjoint `p1` normalizations: **survive**;
- claim that any typed P3 bridge automatically gives surplus `+1`:
  **dissolved and retyped** — only a full index/count output bridge does;
- strict surplus `0`: **survives**;
- normal/tangential connection diagonal obstruction: **survives**;
- K95 right-`H` comparator on K77: **needs-recheck / port unbuilt**;
- K77 closed relative Fredholm domain and index: **needs-recheck / unbuilt**;
- identification with generation count: **needs-recheck / unbuilt**;
- P1/P2/P3, residue, quotients, canon and public posture:
  **survive unchanged**.

## Dissent

One could count "the same integer fits two slots" as two constraints. That is
rejected here because both slots are input assignments related by a constructed
map; neither is an independently observed or action-derived output equation.
If a future K77 index calculation returns the physical count, that dissent
becomes the reason the surplus rises to `+1`.
