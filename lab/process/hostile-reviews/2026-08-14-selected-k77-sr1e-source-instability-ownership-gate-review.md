# Hostile review: SR-1E source-instability ownership gate

## Verdict

`SURVIVES_AS_INTERFACE_TYPE_GATE__SOURCE_INSTABILITY_REMAINS_A_CREDIBLE_BRANCH_GENERATOR`.

The result correctly refuses to turn a negative constant-mode Hessian
direction into a selected canonical stationary first jet. Its conclusion is a
missing typed bridge, not nonexistence of that bridge.

## Strongest attacks

### A tachyonic direction is already a new branch

Rejected. It is a direction away from a critical point. A nonzero critical
point also needs the restricted nonlinear terms and their Euler equation.
Fresh SRC-3 evidence is stronger: the declared norm-square quartic is negative
on an exact ray, so the route needs a full-action repair before it can own a
stable critical point.

### Both carriers describe gauge-potential scalars, so the dimensions need not match

Rejected as an unproved identification. The source result uses `10 x so(6,4)`
constant modes, while selected K77 uses an `Omega^1(Y14,so(7,7))` point value
before first jets. A restriction or induction map could relate them, but that
map is exactly the missing object and the source packet records placement as
absent.

### One can simply choose any negative eigenvector

Rejected for canonical branch status. Such a choice proves an existential
trial direction, not a source-owned or equivariant selector. Exact controls
show that symmetry, tracelessness and nonzeroness alone do not determine a
background-independent negative line.

### The arbitrary exhibited curvature is enough because the theorem is universal

Rejected for branch construction. Universality proves that the canonical
curvature would also be unstable once correctly represented, but it does not
serialize that curvature in the source carrier, select its negative orbit, or
lift the result to a labelled K77 first jet.

### This closes the source Mexican-hat mechanism

Rejected. The instability theorem is preserved and is a credible branch
generator. The next work is constructive: build the equivariant carrier map,
restricted nonlinear potential, selected critical orbit and canonical first
jet. Failure of one of those steps may later kill the route at its exact
scope.

## Weakest seam

The dimensional mismatch is only a gate, never a proof that no representation
bridge exists. Any future result must attack equivariance and action ownership,
not restate `450 != 1274` as a no-go.
