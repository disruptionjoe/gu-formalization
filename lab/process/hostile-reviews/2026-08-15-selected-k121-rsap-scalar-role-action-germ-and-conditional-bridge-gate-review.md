# Hostile review — K121 scalar role and conditional bridge

## Strongest attacks

1. **The source calls the field theta, so it is the horn scalar.** Rejected.
   In the cited passage `Theta` is the full adjoint-valued difference of two
   connections. Symbol reuse does not identify it with a coefficient on the
   invariant `Phi1` line.
2. **The repository already called `I_sc` the scalar irrep of the same
   action.** That supports the role/reduction link, not equality with the
   complete radial restriction. The exact radial restriction contains the
   cubic `1456 t^3` omitted by the minimal horn. Their action germs differ.
3. **Rescale the scalar and the actions match.** No nonzero affine rescaling
   changes zero pure-scalar `D3` into the native value `8736`.
4. **Match the Hessians to fix `|lambda|`.** This imposes an unproved
   cross-action equation, does not fix orientation, and still contradicts the
   third derivative.
5. **Map the stationary values to fix `lambda`.** An origin-preserving match
   makes the slope proportional to `1/rho`; a background-centred affine map
   matches the point for every nonzero slope. Neither is a universal field
   normalization.
6. **A nonlinear field redefinition defeats the obstruction.** It can cancel
   the cubic, but only by adding `q=208 lambda^2/kappa_1`. That unowned scalar
   second jet is precisely a K119 fitted-`D2F` reopening, not current closure.
7. **The result says the dark-energy interpretation was wrong.** It does not.
   The source-level role link to full parameterized torsion survives and is
   the reason `I1B` remains the leading native carrier.
8. **K122 is still blocked because lambda is unknown.** Native assembly is
   not blocked. It uses `t` as the native coordinate. `lambda` appears only
   when translating that native answer into a reduced/observed scalar
   convention.

## Verdict

Pass at exact stationary action-germ and source-semantic grade. The strongest
current hypothesis is a role-linked but action-distinct relation: compute the
complete native `I1B` cubic first, keep `lambda` explicit at the translation
interface, and do not splice `I_sc` coefficients into the native action.
