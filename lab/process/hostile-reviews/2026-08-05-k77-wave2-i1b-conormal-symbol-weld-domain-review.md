## Two-sided findings

### Summary outruns artifact

The first draft compressed the density-line issue into “a length-to-the-tenth
coefficient.” That is only correct when all fourteen coordinates are assigned
homogeneous length units. The metric-fibre coordinates have no such
source-declared assignment. The durable statement is now the missing normal
density or transverse profile; `L^10` remains an explicit comparator.

The same draft described `14*85` and `14*91` as the whole Shiab matrix. The
adjoint coefficient multiplicity was suppressed. The report now says “per
paired adjoint coefficient block.”

### Artifact defends superseded object

No such failure remains. The executable uses an arbitrary Shiab matrix because
the theorem is family-level, not because it wants to promote the earlier
conditional `(9,5)` representative. The live matrix is fenced as nonvacuity
only. The result advances beyond the predecessor's source-shaped proxy and
beyond the superseded zero-jet truncation.

## Boundary

The wave computes the principal symbol of the actual **I1B grammar**, not the
coefficient table of an actual **selected Shiab representative**. At one fixed
section, a special Shiab may still annihilate all 85 mixed-normal inputs while
remaining nonzero on six tangential inputs. That possibility is open until a
source-compatible moving/derivative representative is constructed.

The no-duplicate weld is the primary selected architecture, not a uniqueness
theorem. The common domain is a variation and trace domain, not a Krein Green,
maximal-dissipative, hyperbolic, BFV or physical domain. The primitive epsilon
Ward chain, P1/P2/P3, Wave 3 and every physics row remain unmoved.
