# Hostile review — K77 graded Green reality graphs

## Charge 1: where could the summary outrun the artifact?

The exact theorem proves pointwise graded Lagrangianity on noncharacteristic
normal data and tensorial overlap. It does not prove a closed operator domain,
maximal dissipativity, positivity, Fredholmness, quantum-measure orientation,
or characteristic evolution. The report therefore says **domain candidate**,
not physical domain.

The two pairing structures are complete only inside the tested Spin-natural
action-bilinear class. No claim is made that all possible nonlocal,
pseudodifferential or symmetry-broken boundary relations have been classified.
The old `120` coordinates dissolve only as a claimed physical ambiguity inside
this class.

## Charge 2: where might rigor defend a mistyped object?

Calling the fermionic block an “odd symplectic form” would be imprecise. The
fields are Grassmann odd, but the classical action gives a graded-even Green
two-form whose matrix on odd directions is symmetric. The artifact uses this
typing explicitly.

The pointwise fixed locus is also not the same object as the full moving
boson-fermion preboundary form. Frame covariance differentiates correctly, but
unrestricted bosonic variations can add mixed terms; these remain open rather
than being hidden inside the finite theorem.
