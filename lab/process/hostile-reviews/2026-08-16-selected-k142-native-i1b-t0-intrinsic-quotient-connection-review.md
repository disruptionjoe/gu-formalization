# Hostile review: selected-K142 intrinsic quotient-connection classification

## Strongest overclaim attack

An intrinsic connection on `H_n/G_n` is not the missing action-specific
subprincipal connection merely because both live on the same quotient. The
split calculation proves the opposite: `E dR_mu=0`, so the projected graph
connection is independent of the action-derived `D_mu`. K142 correctly calls
the descended object natural and tautological rather than Dencker transport.

The zero projected contribution is not a zero physical subprincipal symbol.
It says only that graph bending is extrinsic for the fixed split. Lower-order
action coefficients, background derivatives and reduction conventions are not
contained in that statement.

## Strongest contrary construction

Choose a smooth complement to the radical and a gauge slice. This produces a
five-dimensional representative bundle and a matrix for the natural quotient
connection. It does not contradict K142: the quotient connection existed
before the choices, while the displayed matrix changes with the slice.

One can also add a lower-order endomorphism preserving the radical and gauge
image. Such an endomorphism descends and would be action-specific if derived
from the action. The current graph derivative does not select it. K142 leaves
this exact route to K143 instead of promoting an arbitrary choice.

## Basicness and covariance attack

The formula `[h] -> [nabla h]` is well-defined only if `nabla H` stays in `H`
and `nabla G` stays in `G`. K138 supplies both facts for natural transport on
the smooth null patch. The exact probe verifies representative independence
and plants a connection that leaks a gauge vector into a nongauge radical
direction; the latter fails as required.

This result does not extend the rank-five bundle through K137's nonnull or
spacelike-shell strata. It is restricted to the same smooth null family.

## Weakest reproducibility seam

The vanishing `E dR=0` uses the fixed extraction in the declared independent
`(g,T)` coordinates. Under a moving extraction, differentiating `ER=I` gives
`E dR=-(dE)R`, so the proof must be reformulated covariantly. K142 states the
fixed-split scope and does not claim coordinate-free invariance under arbitrary
moving decompositions.

The quotient dimensions and preservation facts are inherited from K138 and
must be replayed if the null form, gauge generator or action branch changes.

## Verdict

Pass at the stated ceiling. K142 constructs the intrinsic natural quotient
connection without representatives and proves that the compact graph's
action-dependent derivative is purely extrinsic. A typed action-specific
five-class subprincipal endomorphism remains open rather than zero.
