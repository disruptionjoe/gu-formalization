# Conditional-build channel read packet

This is the short dispatch surface for Joe-directed source-native conditional
builds. It owns no source interpretation or scientific result. It routes those
jobs to the packets that do, prevents stale tests from becoming new work, and
keeps missing dynamics as dependency fences rather than construction prompts.

## Reverse-conditional protocol

Start with the **superposition hypothesis** as an explicit conditional horn:
assume a compatible source-native realization could exist, then work backward
from the claimed composition to the minimum geometry it would require.

1. State the horn and its claim ceiling. Do not imply that the source, action,
   or repository selected it.
2. Type the desired downstream composition: carrier, both halves/corners,
   operator or map, observation, and exact row/column incidence.
3. Reverse-build the minimum necessary interfaces and compatibility
   conditions. Keep existence, ownership, nonzero value, and physical survival
   as separate predicates.
4. Archaeology-check whether each interface is already owned, current-K77,
   and source-native. Mark a missing type or bridge instead of inventing one.
5. Run the cheapest exact forward-fit test with typed null models, adverse
   controls, kill conditions, survive conditions, and a stated novelty check.
6. Stop at the first unowned dependency. Bank a reusable compatibility result
   or retire the route; do not cross the boundary by manufacturing its owner.

## Off-limit paths

This channel does not build, select, fit, or import:

- a source action, action term, vacuum, background, or external datum;
- a coefficient, family row/alignment, selector, or scale owner;
- a physical quotient, analytic domain, pole, mass, threshold, or observable;
- a standard SO(10) `126`/Higgs-VEV mechanism, ordinary family index, or net-
  chirality substitute; or
- a new K77 object solely to make a stale K95/`Cl(9,5)` test runnable.

Those are dependencies or work owned by another path, not invitations to
expand this conditional build.
