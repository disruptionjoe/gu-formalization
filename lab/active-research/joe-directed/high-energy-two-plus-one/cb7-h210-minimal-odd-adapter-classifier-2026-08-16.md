# CB-7B — minimal odd-adapter classifier

## Outcome first

Start from the reverse-conditional hypothesis that the two summands printed
in an H210 cell can be made homogeneous. On the current source/K77 typing,

```text
parity(d0) = even,
parity(T_H210) = odd.
```

An adapter applied uniformly to the row, column, or whole cell changes both
parities by the same amount and cannot repair their relative mismatch. Any
escape must therefore be **summand-specific**. Exact representation typing
then leaves only one current-custody branch:

```text
declared q_H in the horizontal/external four-plane,
gamma(q_H) after d0,
inherited opposite-half density dual,
H210 term left unchanged.
```

This branch is an algebraically coherent pointwise/principal-symbol
**required type**, not a built or selected operator. The source does not place
`gamma(q_H)` after `d0`, and this lane does not choose a horizontal section.

The superficially symmetric placement `gamma(q_H) T_H210` passes ambient
parity but fails the banked source-module slot. A horizontal Clifford vector
preserves internal chirality, so the A-half output remains `144bar`; same-half
row typing would route it to `zeta+`, whose banked module is `144`. The
conjugate half fails in the same way. Thus H210-side placement is
`PARITY-SAT / SOURCE-MODULE-FAIL`, not a surviving full-cell convention.

The repository-owned tautological trace receiver does not rescue the cell.
It is a **vertical/internal** vector `q_g=g/2`. In the current H210 split,
bare left multiplication leaks the gamma-traceless port; right multiplication

preserve the current `16 -> 144bar` plus conjugate channel.
