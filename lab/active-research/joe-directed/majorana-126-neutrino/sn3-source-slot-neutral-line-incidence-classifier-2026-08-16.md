# SN-3C — source slots versus observed neutral lines

## Result first

The source gives four recurring unbarred coefficient names,

```text
varpi_pp, varpi_pm, varpi_mp, varpi_mm,
```

and four independent barred/formal-star partners. It gives **no** named
coefficient in the displayed southeast quadrant. That simple custody fact has
three exact consequences.

1. The eight printed `Omega0 <-> Omega1` cells are candidate *ports* for a
   Dirac-capable `X_D` incidence only under `SN2-NEUTRAL=Q0`. The `SM1` horn
   removes the weak-doublet neutral line `L^0`, leaving no `L N^c` endpoint
   pair.
2. A right-Majorana-capable `X_R` has zero ports in the displayed `SE=0`
   branch. `SC-OP-05` admits a nonzero southeast rival, but supplies neither a
   cell label nor a coefficient owner. Parent representation support, if
   separately established, would still not be source-cell placement.
3. The same four unbarred owners occur once in northwest `A` and once in
   northeast `B`. Therefore the SN-2 valuation declaration
   `(v(A),v(B),v(C))=(0,1,1)` is not populated by assigning independent scales
   to `A`, `B`, and `C`, nor by generic one-scale-per-owner scaling. It requires
   a specific **leading-support separation** between the northwest
   `star-odot` restriction and northeast raw restriction of shared owners.

This is a classifier of where a coefficient would have to land. It neither
selects a coefficient nor proves that a permitted restricted map is nonzero.

## 5. Shared-owner leading-support separation theorem

The strongest new consequence is valuation-theoretic and uses no new scale.
Let `j` range over `pp,pm,mp,mm`. Give each already printed unbarred owner a
declared valuation `w_j`. After a declared neutral restriction, write

```text
a_j = its leading northwest star-odot contribution to A,
b_j = its leading northeast raw contribution to B.
```

For the independent barred partners, use valuations `bar-w_j` and leading
southwest maps `c_j`. Then, whenever the indicated supports are nonempty,

```text
v(A) = min {w_j     : a_j != 0},
v(B) = min {w_j     : b_j != 0},
v(C) = min {bar-w_j : c_j != 0}.
```

> **THEOREM — necessary support separation for the strict SN-2 horn.** Under
> one valuation per existing source owner, `(v(A),v(B),v(C))=(0,1,1)` requires:
>
> 1. some valuation-zero unbarred support survives in `A`;
> 2. every valuation-zero unbarred owner is annihilated in the restricted `B`
>    leading map;
> 3. some valuation-one unbarred support survives in `B`;
> 4. no barred support below valuation one survives in `C`, and some
>    valuation-one barred support does survive there.

The proof is the displayed minimum formula. In particular, if every shared
unbarred owner has identical nonzero support status in `A` and `B`, then
`v(A)=v(B)` and the `(0,1,1)` horn is impossible. Calling `A` heavy and `B`
suppressed does not make their shared coefficients independently scalable.

Support separation is only necessary carrier algebra. The strict hierarchy
still needs all of the following separately:

- the full `SN2-NEUTRAL-CLOSED` row/column intertwining horn and regular `U`;
- an invertible leading northwest block `A_0`;
- a nonzero leading `B_0` and `C_0` on the same closed neutral carrier;
- nondegenerate `C_0 A_0^{-1} B_0`;
- the declared valuations themselves.

SN-3C proves none of those conditions. It identifies the exact incidence
pattern an already-admitted owner would have to satisfy before the SN-2
valuation theorem can be populated.

## 6. Eight-lens assessment and falsifiers

1. **Source matrix grammar:** all sixteen cells, signs, row reversal, and the
   candidate strength of `SC-OP-04/05` are retained.
2. **Row/column restriction:** formal neutral endpoint pairs do not imply an
   invariant restricted subpencil; `SN2-NEUTRAL-CLOSED` remains separate.
3. **Four-corner classes:** every quadrant has exact `(0,2;2,0)` net-cell
   pattern; centre class and observed charge are never identified.
4. **Observed charge incidence:** Q0 has `L^0` and `N^c`; SM1 has only `N^c`.
   This makes the `X_D` horn empty on SM1 without saying a coefficient is
   absent from the parent.
5. **Both halves and bars:** both source-effective packages and both
   centre-class packages are kept; barred southwest owners remain independent.
6. **Operator parity:** `pp/mm` and `pm/mp` exchange their “within/cross” role
   between the two half ledgers. A bilinear label is not silently turned into
   an unbarred operator arrow.
7. **Valuation hierarchy:** the common `A/B` owner set forbids independent
   block-scale bookkeeping. Only support separation can produce `0/1` from
   one valuation per owner.
8. **Conditional falsifiers:** this result fails if the source matrix was
   mistranscribed, if an existing named southeast owner is found, or if an
   exact source identity makes the `A` and `B` occurrences independent
   coefficients. The hierarchy route fails on the present owners if every
   valuation-zero `A` support necessarily survives in `B` or if every possible
   `C_0 A_0^{-1} B_0` is degenerate.
