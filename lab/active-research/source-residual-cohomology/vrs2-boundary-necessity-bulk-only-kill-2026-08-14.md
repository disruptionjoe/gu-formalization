# VRS-2 boundary necessity and bulk-only kill

## Result first

For the live selected branch with nonzero endpoint charge, a bulk-only physical
quotient is killed. The reason is action-owned, not aesthetic: its endpoint
potential and moment map distinguish gauge degeneracies from charged boundary
symmetries. Removing the endpoint sector or quotienting its transformations as
bulk gauge discards nonzero symplectic and charge data.

The kill is branch and horn scoped:

```text
free endpoint variation     -> p_0=p_2=0 -> zero charge;
                               bulk-only escape remains, live fixture excluded
fixed endpoint data         -> delta g=0, p unconstrained;
                               endpoint movers are charged symmetries, not gauge
charged/edge horn           -> nonzero moment retained;
                               boundary/BFV carrier is indispensable
generated Robin graph       -> possible mathematical horn, but F is unowned
```

No current horn supplies a physical complex domain. The exact W/mirror
base-conormal pair is algebraically maximal isotropic, but the rank-eight mixed
selected gauge image preserves neither member; normal conormals make neither
member isotropic. Moving associated-spinor `J10` also has no total Green domain
or boundary extension. Thus boundary necessity closes before polarization,
positivity or analytic-domain existence.

## Horn theorem

The bare selected action owns

```text
Theta = p_0 delta g_0 - p_2 delta g_3,
Q_eta = p_0 eta_0 - p_2 eta_3.
```

### Free horn

Arbitrary independent endpoint variations force `p_0=p_2=0`. The moment map
then vanishes for every endpoint parameter. This is the only current
action-owned horn on which treating all endpoint transformations as gauge is
not immediately contradicted by nonzero charge. It is a distinct zero-charge
branch and excludes the exact nonzero regular fixture.

### Fixed horn

Dirichlet data makes `Theta` vanish because admitted `delta g` vanishes, not
because `p` vanishes. A transformation with nonzero endpoint parameter moves
the fixed datum. It is not an admitted degeneracy of this variational problem.
The unconstrained momentum and seven coadjoint invariants are physical boundary
labels unless another completion is supplied. Quotienting them in a bulk-only
complex is therefore a category error.

### Charged horn

Retaining endpoint transformations and their nonzero moment map requires the
endpoint phase space, its symplectic structure and a boundary/BFV reduction.
The full 91-ghost algebraic BFV charge closes on the frozen action, but the
rank-70 action has a rank-21 stabilizer and the zero level is nonregular.
Proper functional Koszul--Tate/BFV data, polarization and analytic domain are
still missing. Algebraic closure does not make physical cohomology.

### Generated horn

A Lagrangian graph with `Theta|_graph=delta F` could select a nonzero boundary
law. Neither the source nor selected action owns `F`; it must also satisfy the
seven independent invariant tangencies. This remains a contrary construction,
not an admitted result.
