# GU two-layer action and square-root source reinspection

## Question

Does the released source material say enough to use the second
Yang--Mills--Higgs-like layer to select the remaining projective coefficient
in the K77 trace-`q` fermion operator?

The answer is narrower than either “yes, square it” or “the source says
nothing.” The sources specify a norm-square architecture and an unfinished
two-path cancellation burden. They do not identify the K77 left/right
trace-`q` placements with those paths or provide the independent
second-layer operator against which their square is to be matched.

The load-bearing homonym is **square**. A norm square constructed from the
same residual is automatically defined for every coefficient. It does not
become an independent coefficient constraint merely by being second order.
An independent square-root identity requires a separately typed target and a
map from the first-order paths to that target.

## Three honest second-layer readings

1. **Bosonic residual norm:** closest to draft section 9.2. The trace-`q`
   fermion coefficient is absent, so coefficient-selection rank is zero.
2. **Total residual norm:** motivated by draft equation 9.20 and Portal's
   “entire replacement” language. At fixed coupling its Euler derivative is
   `H_Upsilon^! G Upsilon`; every first-order solution remains a second-layer
   solution. This is the source-stated redundancy, not coefficient selection.
3. **Dirac-square/path adapter:** closest to the square-root and
   up-over/over-up language. It is the only reading that could independently
   select the coefficient, but only after constructing the path maps and the
   second-layer target. Released sources do not supply either identification.
