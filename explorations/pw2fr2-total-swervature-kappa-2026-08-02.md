# PW2F-R2 action-derived eddy candidate and universal kappa

## Result in plain English

The source did not hand us another term to bolt onto the action. It handed us
a consistency demand: the curvature contraction by itself is not the
differential of the desired action, and a quadratic eddy must complete it.
The 2021 draft also writes the first action with the coefficients (1/2) and
(1/3). The mathematically safe move is therefore to vary that action and
treat any remainder beyond the compact curvature formula as an eddy candidate
whose identity with Portal's tensor still has to be proved in the full geometry.

That directional remainder is real. It vanishes in the cyclic identity-contraction
control, which explains the compact formula in the draft. It is nonzero for
the repository's noncyclic moving-contraction fixture. On a flat connection
reference its distortion scaling is exactly

\[
E_{\rm rem}(rT)=-15r^2,
\]

so it has precisely the quadratic behavior suggested by Weinstein's Portal
description. On the selected nonzero connection reference it becomes

\[
E_{\rm rem}(rT)=-5r(3r+1).
\]

The linear cross term is important: it says the flat-reference quadratic
description cannot simply be promoted to every connection background. It
passes exact constant-conjugation witnesses when the contraction insertion
gauge-co-moves, and a frozen-insertion control fails. The insertion is frozen
during the field variation in this fixture; the actual eight moving-Shiab
variation slots remain open.

The same exact action fixture then supplies a clean test of the idea that one
special value of (kappa_1) might remove the fourth-order equation. It does
not reject fitting by reflex; it computes the surplus condition.

For a fixed-total-connection split

\[
B_x=B+xK,\qquad T_x=T-xK,
\]

the endpoint connection and its curvature stay fixed for every (x). The
complete finite action polynomials are

\[

\frac{2x^3-3x^2-40x+19}{2}
+\frac{\kappa_1}{2}(7x^2+4x+2),
\]

\[

\frac{4x^3-15x^2-98x-63}{3}
+\frac{\kappa_1}{2}(7x^2+4x+2).

Their exact Hessians—the scalar C4 comparators after (x) is typed as the
second-jet owner—are

\[

\qquad
C_{4,\rm mov}=7\kappa_1+8x-10.
\]

At any one background, these can be tuned to zero. But the roots

\[

\qquad

vary with the background. There is no constant (kappa_1) cancelling either
whole family. The earlier (-3/8) root belongs to a different bridge-amplitude
fixture and fails this test.

This is a useful no-go of the narrow, constructive kind: if a universal
action identity selected one (kappa_1), it would have to survive this exact
ambient independent-((B,T)) finite (I_{1B}) restriction. It does not. That
family need not lie in the actual induced geometric graph. A special cancellation on the much smaller actual
induced-(Y^{14}) geometric locus remains logically possible and must be
computed rather than assumed.
