# M-M3 — the parity theorem is about the FULL quaternionic commutant

**What this is.** Register item M-M3: a strengthening of the C-07
quaternionic-parity no-go (`canon/no-go-quaternionic-parity-generation-sector.md`).
The no-go proves every GU-native primitive commutes with J_quat, i.e. the
generated algebra is *contained in* the J_quat-commutant. This note proves the
containment is an **equality**: GU's building blocks generate the entire
commutant. That upgrade reframes the no-go's scope — and it corrects, in
passing, the misidentification of the commutant itself (audit item RT-F4).
A Layer-0 fence up front: **this derives no count**; it says what the class of
GU-native carriers *is*, not which carrier (or rank) is selected.

## Setup and the commutant correction

The C-07 carrier space is C^14 (x) C^128 = C^1792 with
J_quat = id_14 (x) C·conj, C = e1 e3 e5 e7 e10 e12, J_quat^2 = -1
(antilinear). The commutant of an antilinear J with J^2 = -1 on C^N is the
algebra of H-linear maps of the quaternionic module (C^N, i, J):

```text
Comm(J_quat) = M(14,R) (x)_R M(64,H) = M(896,H),
dim_R = 196 x 16384 = 3,211,264 = 1792^2 = 4 x 896^2.
```

Canon's line ("the J_quat-commutant M(14,C) (x) M(64,H)") is wrong on the
first factor: i·id_14 ANTI-commutes with the antilinear J_quat
(J(i v (x) s) = -i J(v (x) s)), so M(14,C) (x) M(64,H) (dim_R 6,422,528) is
not inside the commutant at all — only its real-first-factor subalgebra is.
The containment the theorem actually uses is unaffected (the correct
commutant is smaller, so the no-go's premise is *a fortiori* true, and the
Kramers argument only ever used J-commutation itself). Canon receives a dated
bracket note at that line in this batch; no verdict changes.

## Theorem (strengthening)

**The real algebra generated by GU's a-priori building blocks (the C-07 list:
e_a including the timelike i·G_a, sigma_ab, omega, the vector generators M_ij,
Pi_RS and Q, M_D, the BV/ghost apparatus) is the FULL commutant
M(14,R) (x) M(64,H) = M(896,H).**

*Proof.* (⊆) is C-07's per-generator exact certificate: every named primitive
commutes with J_quat bit-exactly (`tests/big-swing/c07_kramers_regression.py`),
so the generated algebra sits in the commutant. (⊇) needs only two of the
primitives, M_ij and e_a, and is Burnside twice. Vector side: so(9,5) acts irreducibly on R^14 and its
complexification C^14 is irreducible under so(14,C), so the representation is
absolutely irreducible with commutant R; by Burnside/Jacobson density the
unital real algebra generated by the M_ij is all of M(14,R). Spinor side: the
e_a generate the full real Clifford algebra, Cl(9,5) = M(64,H)
(dim_R 2^14 = 16384, Lawson-Michelsohn/Harvey classification). The generated
algebra therefore contains M(14,R) (x) M(64,H), which by the dimension count
above IS the commutant (a simple subalgebra of equal finite dimension is the
whole). QED

Session numeric check (scratchpad script, `_local/cas-venv` python, exit 0):
the commutant of the 91 so(9,5) generators on R^14 has dimension exactly 1
(rank of the 91x196-row commutation system = 195), and the same over C
(absolute irreducibility); dimension arithmetic
196 x 16384 = 3,211,264 = 1792^2 = 4 x 896^2 asserted exact.

## Consequences

1. **"GU-native" ≡ "H-linear", and nothing more.** The no-go's operator class
   is exactly the H-linear (J_quat-commuting) operators — not an artifact of
   the particular generating set. There is no hidden further constraint
   waiting inside the building blocks: anything H-linear IS built from them.
   This makes the Kramers wall a statement about a *structure* (the
   quaternionic module), with zero residual dependence on GU's inventory.

2. **Every even index is realized by some GU-native carrier — the wall is
   sharp.** For any quaternionic ranks (s,t) with s + t <= 896, the H-linear
   Hermitian carrier P_s - P_t (difference of H-rank s and t projectors,
   available inside M(896,H) by (1)) has index 2s - 2t. So the realizable
   index set of GU-native carriers is EXACTLY the even integers in range:
   even <=> GU-native-realizable. Kramers gives "only even"; equality of the
   algebra gives "all even". The no-go's one-way wall becomes a two-way
   characterization.

3. **count = dim_H (= index/2) is the natural reading, not an alternative.**
   Since every GU-native carrier is an operator on the quaternionic module
   H^896, its intrinsic integer invariants are quaternionic: H-ranks and the
   H-index (half the real/complex index). Canon's C-06 presents "count =
   index/2" as an *alternative* reading beside the literal-index reading; with
   (1), the H-index is simply the native invariant of the native class — the
   literal (complex) index is the H-index seen through a forgetful functor,
   with Kramers' factor 2 as the exchange rate. Under the native reading every
   integer count (including 3) is realizable and none is forced — exactly
   C-06's under-determination, unchanged.

## What this does NOT do (Layer-0 fence, and scope)

- It derives **no count**. Realizability of every even index (or every
  H-index) is the opposite of a selection: the rank remains free, which is
  C-06's under-determination verbatim. Nothing here picks 3, 6, or any number.
- It does not weaken the no-go: for the literal-index reading, odd indices
  (hence 3) remain unreachable natively; the strengthening says this exhausts
  the obstruction.
- Signature scope is inherited unchanged from the no-go's own caveat: all of
  this is (9,5)/H-class specific (J^2 = -1). Under a (7,7)-type real class the
  quaternionic structure, the wall, and this strengthening all dissolve
  together; that fork is register item M-H4, not this note.
- The canon edit executed with this note is the one-line commutant correction
  (bracket note at `canon/no-go-quaternionic-parity-generation-sector.md`,
  citing this file); the no-go's verdict line is untouched.
