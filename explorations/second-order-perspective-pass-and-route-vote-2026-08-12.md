# Additive findings from a second-order perspective pass

A twenty-perspective pass proposed six routes; running the same perspectives
against that analysis produced the following items, none of which the
cadence's own correction carries. Everything the cadence already owns is
omitted by design (see `scope_note`).

## Typing corrections

- **Indefinite-signature rigidity trap (Layer-0).** "Once `J` exists,
  exploit holomorphic rigidity" does not transfer: `U(3,2)` is
  pseudo-Hermitian, and Liouville/identity-theorem rigidity is a
  definite-signature phenomenon. Complex-geometry constraints must be
  re-derived in indefinite signature before being counted as equations.
- **The `J`-quotient is double-edged.** If the action/observation
  quotient of the 20-dimensional orbit is a point, `J` is pure gauge —
  which also makes `D_varpi J = 0` automatic rather than informative.
  Read the quotient as TYPING that gate, not only as deleting twenty
  coordinates.
- **Krein-null is a selection debt in disguise.** Quotienting by a null
  cone is degenerate unless a complement is chosen; that choice is
  unbooked data, not a free step.

## Cheap tests and sequencing

- **First test for the universal-leakage route:** compute the ten
  `D_i = (H_640 + E_i H_640)/H_640` and check pairwise isomorphism as
  modules over the stabilizer. Agreement puts the class in a single Ext
  group; disagreement kills the universality premise cheaply. (This pass
  votes the leakage route higher than the source analysis did, on the
  strength of this test existing.)
- **Atlas sequencing.** A discriminant/bifurcation atlas needs a finite
  parameter list; the live space is still function-valued, so the atlas
  is a successor to debt reduction, not a parallel track. Cheap seed
  already in-tree: the pairing determinants in the v0.173/v0.174 banks.

## Two proposed queue additions

- **Aggregate debt recount** after the quotient and leakage routes,
  typing each surviving freedom by what would fix it — gauge choice /
  boundary condition / moduli point / external datum. Nobody currently
  computes the number that says how much genuine debt remains.
- **Independence-certificate verdict class**, so "provably undecidable
  from present premises" becomes a terminal result that stops a search
  rather than an open row that keeps accruing waves. Prerequisite: the
  premises must be finitely axiomatized; the source-claim register is
  the start of that list.

## Process datum: a false-novelty near-miss

`novelty-check.py` on "Hilbert 90" and "Galois descent" returned zero
exact hits, and this pass nearly filed a novelty claim on that basis.
The prior art was five hours old and written in different vocabulary
("additive finite-group cohomology", "averaging"); only reading the
cadence's latest commit before filing caught it. **Zero exact hits is
not evidence of new, and vocabulary mismatch is the standard way the
check fails.** Suggested, wave-owned: novelty checks on a mathematical
construction should grep the concept's MECHANISM words, not only its
proper-noun name.
