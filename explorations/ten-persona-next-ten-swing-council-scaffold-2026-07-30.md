# Ten-persona inverse-construction council

## Decision

The next campaign is not another search for whether GU needs a source action
and external datum. That is already the premise. It is a **stateful inverse
construction**:

\[
\mathcal C_0
\supseteq \mathcal C_1
\supseteq \cdots
\supseteq \mathcal C_{10},
\]

where each \(\mathcal C_i\) is an explicit family of source-action, datum,
solution, domain, and reduction packets. Every swing must do one of two
things:

1. add a written term, map, datum interface, equation, solution, domain, or
   index construction to the inherited candidate; or
2. eliminate a mathematically specified candidate stratum with a controlled
   calculation.

The following are **inadmissible bottom lines** for a swing:

```text
SOURCE-ACTION-MISSING
EXTERNAL-DATUM-NEEDED
DOMAIN-NOT-SUPPLIED
VACUUM-UNKNOWN
MORE-HARDENING-REQUIRED
```

Those statements may explain why a particular candidate stratum dies, but
they are not progress and cannot be the result. A failed construction must
return an explicit smaller family, a minimal inconsistent equation set, or a
typed obstruction class that fixes the next term to be constructed.

The integrated ordering is:

```text
N1  write one unified source-action + datum candidate family
  |
  +--> N2a actual-Sym2 odd bilinear/orbit screen ---------------+
  |                                                            |
  +--> N4a curvature-irrep decomposition (parallel cheap leg)   |
  |                                                            v
  +--> N3 vary and reduce the written candidate ---> N2b formal Euler hull
                                                \--> N4b source-EOM/open-BV factor
                                                               |
                                                               v
N5  solve the unified quadratic five-leg candidate variety
  -> N6 nonlinear BV/higher-bracket completion
  -> N7 curved local/formal gravity/DE + sourced causality/UV solve
  -> N8 common Green/BFV domain + full graded transport
  -> N9 closed X4 reduction + physical Hessian/SM/anomaly packet
  -> N10 actual twisted-RS analytic index realization + held-out tournament
```

N2a and the algebraic part of N4 are the first cheap, high-branching
discriminators and may run in parallel after N1. N2b and N4b wait for N3's
actual variation. N3 is not a requirements audit: it must vary and reduce the
written action. N5 is the first hard campaign gate. N10 does not set an
integer equal to three; it constructs the index map and asks whether the other
four legs select a discrete topology without target coding.

This artifact scaffolds the ten swings. It executes none of them.
