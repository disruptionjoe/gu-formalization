## 2. Method: one record-sector certificate (plus an ambient consistency check), no blind 1664^2 solve

**(i) Spectral-graph certificate on `V` (the record-sector computation that
bears).** A generic Hermitian element `H1 = sum_i c_i K_i + h.c.` (complex
Gaussian `c_i`) lies in the complexified algebra because the generator family
is adjoint-closed (verified). `H1` has simple spectrum (min gap `1.3e-3`
against spread `80.1`), so any commutant element is diagonal in its eigenbasis;
each further generator `K` forces `d_i = d_j` wherever `(W^dag K W)_{ij}` is
genuinely nonzero. The number of connected components of that graph equals
`dim_C` of the commutant. Computed: **1 component**, stable across edge
thresholds `1e-4 / 1e-6 / 1e-8` (relative, per generator) and replicated by an
independent seed on an independently drawn 22-generator subfamily (also 1, min
gap `9.2e-4`). Because the component count is identical at the very
conservative `1e-4` threshold (strong edges only), the conclusion does not
depend on any near-threshold matrix entry (the probe's printed edge-separation
line is a diagnostic, not evidence). Since commutants only shrink when
generators are added, `dim_C = 1` for this sub-list certifies `dim_C = 1` for
the full generating family stated in the task. The antilinear leg: every
generator is H-linear (`J`-commuting, defects `< 1e-11`) and `J` preserves `V`,
so the real commutant is `C·I + C·I·J = span_R{I, iI, J, iJ}` with

**(ii) Ambient tensor-shortcut consistency check.** Anything commuting with the

`Y (x) (H-linear scalar)`: the spinor-factor commutant of `Cl(9,5)` on `C^128`
