gauge/BV--Koszul--Tate sequence.  It does **not** have enough structure to
turn either nonzero Higgs-branch Euler obstruction into zero.

This matters because two different ideas had been grouped under “build the
full BV/KT tangent”:

1. ordinary gauge/BV/KT machinery records source-coordinate redundancy,

second would have to be supplied by an additional action-owned reduction,
constraint term or equivalent physical construction.

after the quotient.  Koszul--Tate exactness therefore certifies consistency of
the Euler ideal; it does not certify stationarity.

## Koszul--Tate typing

For a pulled-back Euler covector `E_source = S^T E`, the minimal algebraic KT
pattern is

```text
delta_KT phi* = E_source,
delta_KT c*   = R^T phi*,
delta_KT c2*  = Z^T c*.
```

Nilpotence requires

```text
R^T E_source = 0,     Z^T R^T = 0.
```

The exact probe verifies both identities for the fourteen-cell and
twelve-cell Euler covectors.  It also verifies, in both cases,

```text

```

That is not a contradiction.  `delta_KT phi* = E_source` is precisely how the
KT differential resolves the nonzero Euler ideal.  An equation becoming
KT-exact is not the same statement as restricting the primal tangent until
the equation vanishes.

The planted control adds an explicit rank-14 primal constraint `C` whose
kernel excludes the diagonal obstruction cells.  On that genuinely different
object, the Euler covector does vanish on admissible variations.  The control
proves that the gate would recognize a real constraint if the source action
owned one.
