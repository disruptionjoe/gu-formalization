## 2. All-pair native vertex theorem

For nonzero real null covectors p,q and arbitrary spinor column chi and independent row beta define

    U_p(chi): z_j=p_j chi, nu=0,
    V_q(beta): eta^j=q^j beta, eta_scalar=-beta c(q).

Then

    sigma_s(p)U_p=(0,p² chi),
    V_q sigma_s(q)(z,nu)=q² beta[-c(z)+(1-s)nu].

They are therefore exact principal right and left null states for **every scalar s**, not only the held repair. These gradient-shaped polarizations are not an asserted gauge orbit. A symbol kernel alone does not provide a physical BRST quotient.

The exact paired vertex is

    V_q V_a U_p
       = beta[(p·q) Gamma a - c(p)a(q)-c(q)a(p)]chi,
    Gamma a=sum_j gamma^j a_j,  a(p)=sum_j p^j a_j.

For a=i alpha Id this becomes i beta c(L(alpha))chi, where

    L(alpha)=(p·q)alpha-(alpha·q)p-(alpha·p)q.              (1)

**Theorem.** For every nonzero real null p,q, some real alpha and admitted beta,chi give a nonzero real-action current.

**Proof.** Clifford contraction is injective: c(v)=0 implies, by anticommuting with c(w), that v·w=0 for every w, hence v=0.

- If p·q is nonzero, span(p,q) is nondegenerate. Choose nonzero alpha in its twelve-dimensional orthogonal complement. Then L(alpha)=(p·q)alpha is nonzero.
- If p·q=0 and p,q are independent, choose alpha with alpha·p=0 and alpha·q nonzero. Then L(alpha)=-(alpha·q)p is nonzero.
- If q=c p, c is nonzero. Choose alpha·p nonzero. Then L(alpha)=-2c(alpha·p)p is nonzero.

A nonzero Clifford matrix has a nonzero row/column element. An independent constant phase of beta makes the real part of i beta c(L(alpha))chi nonzero. This last freedom is not assumed for an unspecified linked-row positive contour. QED.
