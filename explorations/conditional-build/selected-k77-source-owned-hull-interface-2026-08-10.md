# Selected K77 source-owned hull interface hardening

## Result

The current build is worth continuing, but not by inventing 128 new fermion
fields and not by fitting a receiver projector.

v0.159 established exactly that each tested timelike, spacelike and null
symbol needs a rank-256 equation receiver: the original rank 128 plus 128
additional directions, with 128 paired left directions required by the Krein
action typing. Its summary called those added directions unowned fields.

The primary-source collision narrows that statement. The 2021 fermion grammar
already declares four independent fields:

```text
nu, bar-nu     in Omega^0(Y,S)
zeta, bar-zeta in Omega^1(Y,S).
```

The extra paired directions therefore have an already-declared ambient field
type. What the source does **not** own is the particular finite reduction that
selects them. This is the load-bearing Layer-0 correction:

> source ownership of an ambient carrier is not source selection of a finite
> subbundle inside it.

There is a second fence. v0.159 found rank 256 separately at three covectors.
Equal dimensions do not show that the receiver subspaces are equal. One fixed,
covector-independent hull has not yet been computed or selected.

## Why this changes the next construction

The previous next gate could be read as “add 128 fields.” That would debit the
program before checking the source grammar and invite a fitted closure. The
correct next gate is narrower and more informative:

1. form one fixed common hull across the tested covectors;
2. test whether the action-owned moving reduction preserves it, using the
   candidate conditions `P_epsilon u=u` and `D_varpi chi_epsilon=0`;
3. compare its selectivity against the graph, mirror, random graded 192s, 640
   and 832;
4. stop if only a covector-dependent fitted projector or unrestricted
   function-valued map selects the result.

This is still construction-first. The ledger hardening was stopped as soon as
it supplied a typed interface and an early kill condition.
