## 3. One-sided boundary relation, with no singular projector

Let lambda=sqrt(delta)>0. In the regular coordinates the equation is

`q'=p−g0(t)`, `p'=lambda²q−g1(t)`.

For `b=p+lambda q`, it becomes `b'=lambda b−(g1+lambda g0)`. Removing the future-growing component gives exactly

`b(0)=integral_0^infinity e^(−lambda s)[g1(s)+lambda g0(s)] ds`.

For a pair with temporal phase nu the boundary numerator is divided by `lambda−i nu`. q(0) is free and p(0)=b(0)−lambda q(0). For example, q(0)=0 is a regular mathematical representative of this affine relation; it is not an adopted physical selection rule. Changing q(0) adds an arbitrary decaying homogeneous state.

The equivalent equation using `(N+lambda Pi)x` can obscure this regularity: solving it using the separate growing projector introduces a spurious 1/lambda in the coordinates. The full regular frame avoids that operation. The homogeneous propagator is

`exp(tN)=cosh(lambda t)Pi + [sinh(lambda t)/lambda]N`,

with a finite limit on any bounded time interval. In coordinates its limit is `[[I,tI],[0,I]]`. Given bounded regular boundary data and bounded smooth forcing, the quadratic state is consequently Fourier-locally L2 for each fixed finite t. For arbitrary bounded forcing this finite-time statement need not be uniform in time. The particular smooth packets have a stronger property proved next.

At the exact threshold a single constant plane-character force has a secular response. Plane characters are not the compact-packet L2 data here. We define the packet boundary through its one-sided lambda↓0 limit; the hypersurface itself has zero Fourier measure. ### Uniform forward-time bound for these packets

The same submersion supplies more than an initial boundary value. Integration by parts in the relative input variable, or Fourier transformation of the smooth compact coarea density, shows that the actual quadratic force and its regular-coordinate components obey

`sup_K |g_j(t,K)| <= C_N (1+t)^(-N)` for every fixed N,

on the held compact output collar. The constants depend on Fourier derivatives of the fixed input amplitudes. There is no stationary relative phase on these patches. In particular the forcing has an integrable first time moment.

Write `h=g1+lambda g0`. The future solution for the boundary combination is

`b(t)=integral_t^infinity e^(−lambda(s−t)) h(s) ds`.

Let `||.||_1` denote integration over positive time, with sup over this K collar. For `0<=lambda<=lambda_max`,

`sup |b(t)| <= ||h||_1`,
`integral_0^infinity |b(t)| dt <= ||t h||_1`.

Since `q'=−lambda q+b−g0`,

`sup_(t>=0) |q(t)| <= |q(0)| + ||t h||_1 + ||g0||_1`,
`sup_(t>=0) |p(t)| <= ||h||_1 + lambda_max sup |q(t)|`.

The displayed pointwise bounds integrate over the compact K collar for any such q(0); the smooth forced terms are bounded there.
