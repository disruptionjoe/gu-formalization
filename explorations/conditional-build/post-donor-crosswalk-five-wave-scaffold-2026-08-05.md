# Post-donor-crosswalk five-wave scaffold

## Objective

Keep the conditional GU construction on its three live fronts while using the
two selected donor methods only where they reduce a named distance. Construction
remains primary; cross-theory comparison stops.

## Wave 1 — selected `Y14` cubic numerator on the physical quotient

**Channel:** Build. **Primary row cluster:** `LT-GR2b`, `LT-GR3`, `LT-GR5`,
`LT-SM8`.

Construct the actual selected momentum-space numerator for the
`theta(q0+qm)^2` vertex after moving observation, Ward/BV reduction and the
presymplectic/preboundary quotient. Evaluate it on both exact odd-channel
shells. Only then ask whether `Q1=-2N/D` has a nonremovable physical-sheet pole.

**NCG control substep:** type the external fermion/scalar leg, grading, real/
Krein structure and charge-conjugation placement. Do not import the finite
algebra or `D_F`.

**Pass:** a nonzero reduced numerator or an exact cancellation theorem.
**Kill:** numerator is exact/gauge or zero on every selected shell.

**Wave-1 result (2026-08-05): partial pass; continuation generated.** The exact
full-pencil legs make the compact-core `theta-q0-q0` bulk numerator zero on the
free shell. The inherited `hh` response does not select the mixed
`theta-q0-qm` class: an `hh`-only completion gives `dM^2/2`, while a
full-pencil field-redefinition completion with the same inherited `hh` block
is EOM-exact and gives zero on every free shell. This is a construction fork,
not a theory kill and not a Q1 pole. Before Wave 2, Wave 1A must construct the
complete moving `D^3 I_selected`, including the `h-v` block, observation and
section response, Shiab/Hodge/DeWitt/Krein pairing, gauge-rotated
Levi--Civita soldering, trace/traceless distortion, compensator and
Green/preboundary response. The unrestricted BFV class remains open.

## Wave 2 — native normalized observer/domain functional

**Channel:** Build. **Primary rows:** `LT-GR2b`, `LT-GR2d`, `LT-GR3`.

Place a normalized covariant functional in the same action and domain as the
moving observation map, prove invariance/normalization, and rerun the constant-
shift and curvature-tracking tests. Price every supplied window, state, measure
or boundary choice.

**LQG negative control:** do not accept a cylindrical connection-space measure
unless an explicit functor preserves the GU carrier, covariance and zero-mode
observable.

**Pass:** the functional is action-owned or supplied with its datum cost and
the shift response is exact. **Kill:** normalization or covariance requires an
unpriced choice, or the projector does not descend to the physical domain.

## Wave 3 — super-IG local bracket and global higher-group descent

**Channel:** Build. **Primary rows:** `LT-SM8`, `AC-A1`, `AC-A2`, `AC-A3`,
`AC-A4` where applicable; do not invent an odd action row.

First compute the equivariant Hom space for the proposed symmetric odd bracket
into connection one-forms. If nonzero, construct the bracket, test higher
Jacobi/CE closure, period and integrality conditions, real/right-H/Krein
compatibility, then integrate it using the selected L-infinity method.

**Pass:** a zero-free-parameter global action on connection space, or a scoped
no-go locating the missing datum. **Kill:** equivariant Hom vanishes, Jacobi
fails, periods are non-integral, or a free level is required.

## Mandatory reconciliation checkpoint

After Waves 1--3, Compose runs before another expensive Build. It updates the
ledger only if mathematical evidence changes a row; otherwise it records the
explicit no-change reason, rechecks aliases/high-fanout premises and chooses
which remaining distance actually dominates.

## Wave 4 — full GU-native Standard-Model recovery control

**Channel:** Compose plus targeted Build. **Rows:** `LT-SM1`, `LT-SM2`,
`LT-SM4`, `LT-SM5`, `LT-SM6`, `LT-SM8`.

Run the Connes finite-control roles over the completed GU-native map: algebra/
representation, grading, real structure, order conditions, gauge orbit,
Higgs representation/potential, Yukawa/mass placement, unimodularity,
hypercharge, anomaly and action recovery. Each row must say `DERIVED`,
`CONDITIONAL`, `IMPORTED`, `PUT_IN`, `WRONG_TYPE` or `OPEN` and name the single
distance to improvement.

**Pass:** a referee-auditable SM recovery map with no hidden imports.
**Kill:** any claimed derivation depends on the prohibited finite NCG object
port or carrier containment alone.

## Wave 5 — conditional UV admission, not automatic FRG

**Channel:** Build only if admitted; otherwise Compose selects the next native
construction.

Admit the existing asymptotic-safety/FRG machinery only if Waves 1--4 leave a
stable action, coefficient set, field content and common domain. Then rerun the
UV test across declared truncation, regulator and field-parametrization
families and report universal versus scheme-dependent outputs separately.

If those prerequisites are absent, **do not run FRG**. The fifth wave becomes
the highest-information native Build task selected at reconciliation.

## Standing review discipline

Every Build has a lightweight divergent preassessment and the two-sided
hostile post-review. Actions, charges, BV quotients, observation descent and
physical transitions also require the symplectic-geometry veto. A result may
close a route without killing the parent construction: distinguish local route
kills, fork kills and theory-level incompatibility explicitly.
