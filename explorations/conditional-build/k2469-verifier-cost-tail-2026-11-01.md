## 1. Stochastic endpoint theorem

Continue a prospective schedule through the Nth actual use, even on paths
where the real experiment would already stop at failure. Let W_N(q) be its
random charge, excluding S. Couple every q using the same routing uniforms
and the same independent label uniforms. The number and positions of tests
before N uses do not change. If cT>=cQ, each realized charge is nondecreasing
in q. Therefore the LEFT endpoint q_N of F_N minimizes every prospective
cost quantile at this N; use the right endpoint when cT<cQ. Equal charges
make q irrelevant to cost. Integer quantiles can tie for an interval of q;
this gives an optimal representative, not uniqueness.

Fix a tolerated cost-failure probability delta. Minimize integer K such that

    P[S+W_N(q)>K]<=delta, N D(q)>=Aconf.                (1)

Any certified incumbent K0 bounds every improving N by
N<=floor((K0-S)/cU), because W_N>=N cU deterministically. Enumerate those
counts, discard empty F_N, and test q_N. This is a global optimizer for(1),
not merely a continuous or grid approximation. Exact algebraic equality

## 2. Exact tail recurrence

The probability generating function is

    E z^W = [(1-pi) z^cU /
                  (1-pi(1-q)z^cQ-pi q z^cT)]^N.       (2)

This is the negative-multinomial schedule, retaining both test-count and
expensive-label randomness. Put u=cQ,v=cT,a=pi(1-q),b=pi q. For test-cost
coefficients f_m, differentiation of(1-a z^u-b z^v)^(-N) gives

    f_0=(1-pi)^N,
    m f_m=a[m+(N-1)u]f_(m-u)
                        +b[m+(N-1)v]f_(m-v),         (3)

with negative-index coefficients zero. Consequently

    P[W_N>K]=1-sum_(m<=K-N cU) f_m.                   (4)

No independence between resource quality and pass/failure is needed for this
prospective distribution, because the schedule is extended with independent
uniforms. Actual spending until failure or N uses is pathwise at most S+W_N.
Hence a risk certificate with failure probability alpha and(1) jointly
control erroneous passing output or budget exceedance by alpha+delta.
This is an UNCONDITIONAL union bound. Conditioning on passing can amplify
either probability; the theorem does not give a conditional-on-pass budget.
It also does not optimize the smaller outcome-correlated actual-spending
quantile; that requires the actual resource/outcome process.
