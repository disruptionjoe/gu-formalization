# Selected K77 fixed common receiver hull

## Result in plain English

The three causal slices do **not** share one rank-`256` receiver.

Each timelike, spacelike and null slice separately needs `256` receiver
directions. But any two of those rank-`256` subspaces intersect only in the
original rank-`128` receiver and together span rank `384`. Adding the third
slice does not enlarge that join. Both exact Pin placements produce the same
rank-`384` common hull: their joined and intersecting ranks are both `384`.

So the smallest tested covector-independent version of the graph construction
is:

```text
original receiver                 128
common added equation directions +256
fixed common receiver hull        384
paired left/action hull           384
```

The prior rank-`256` number was correct per stratum and wrong as a fixed-hull
candidate. This is exactly the distinction v0.160 left untested.
