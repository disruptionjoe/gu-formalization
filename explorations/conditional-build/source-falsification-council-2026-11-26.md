Let S be a set of allowed mathematical solutions, H the observed histories,
and q:S→H the literal observation. Suppose pi:S→Q is a surjective quotient and
q=qbar composed with pi. Then

    image(qbar) = image(q).

Proof: every quotient element has a representative; each representative has
exactly its original observed history. Both inclusions follow immediately.
This is elementary factorization, not a novel theorem.

The existing trace-plane CK construction makes q surjective onto local analytic
column histories. Consequently **identification alone**, with the same admission
set and readout, cannot select a proper subset of those histories. It can remove
bulk redundancy while leaving every visible history possible.

This separates two questions previously combined in5s.1:

- **Admission:** which solutions are allowed? A restriction, interacting
  constraint, paired reality condition or state-selection law can change image(q).
- **Equivalence:** which allowed solutions represent the same physical state?
  Identification compatible with unchanged q does not change image(q).

Changing the observable also changes the premise. BRST cohomology involves a
closed-state condition before quotienting exact states; this argument does not
ignore that numerator condition or exclude BRST. It only prevents attributing
history selection to the denominator alone.

unrestricted analytic column category. **NOT MODELED / UNDETERMINED:** the actual
physical admission set, physical observable and full interacting cohomology.
