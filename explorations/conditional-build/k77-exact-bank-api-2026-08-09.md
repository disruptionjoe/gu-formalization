# K77 exact coefficient-bank API

## Outcome

The mandatory process gate before the next scientific Hessian swing passes.
The selected K77 carrier and the complete rational v0.122 fixed-operator bank
are now a 134,336-byte versioned artifact rather than an implicit product of a
recursive predecessor tree. The one-time build records 29 source, producer and
nested-dependency hashes. The ordinary consumer imports in `0.004110 s`, loads
and verifies the bank in `0.007037 s`, and never executes a predecessor probe.

This changes the cost of asking the next question from a tens-of-minutes
reconstruction to a millisecond integrity check plus a bounded exact replay.
It does not change a physics verdict.

## Pre-wave

- Fork assumed: the bank preserves the already-declared **selected real
  Spin(7,7) conditional parent**. It does not assume or port either the two
  `U(32,32)` halves or full `U(64,64)` parent.
- Search space: three causal banks, each with ten metric and 91 epsilon
  directions into 1,274 labelled grade-two receivers, with rational
  `1,b,t` coefficients. Serialization is wholesale; parent extension is not.
- New unowned object: none in the physics. The API is repository-owned process
  infrastructure with an explicit custody registry.
- What dies on success: recursive predecessor reconstruction as an ordinary
  consumer path. The original scripts remain immutable dependencies and the
  one-time builder remains available when a dependency legitimately changes.

## Layer 0 and source return

The source grammar, repository coefficient construction and serialized cache
are three different objects. Weinstein does not prescribe an API, hash or
cache policy, so the source return is `SOURCE-SILENT`. The exact bank inherits
the construction's action, carrier, Shiab and receiver scope; it does not make
those choices authorial.

## Exact interface

`k77_exact_bank_build.py` is the only recursive path. It captures the original
v0.122 `30/30` certificate, records every nested repository dependency and
emits canonical JSON. `k77_exact_bank_api.py` then:

- rejects duplicate keys, payload mutation, stale dependency hashes and wrong
  carrier/receiver shapes;
- returns sparse exact `Fraction` columns;
- exposes labelled K77 carrier, causal and receiver metadata; and
- contains a small independent carrier core for bounded epsilon-cell replay.

The fixture explicitly says `NOT_PORTED` for both the two-`U(32,32)`-half and
full-`U(64,64)` parents. That fence prevents the fast path from laundering a
selected-Spin result into a larger action parent.
