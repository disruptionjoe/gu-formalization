# Selected K77 relative chiral-transgression ownership

## Result in plain English

The source-owned reference connection `A0` solves a real global problem, but
not the selector problem.  Because `A0` is a connection on a labelled copy of
the same principal bundle `P_H`, the relative edge bitorsor is nonempty in
every already-owned topological sector.  Its canonical identity section has
zero relative winding and the two connections have the same absolute
characteristic class.  Global existence therefore supplies the **zero**
relative sector, not a nonzero integer.

A nonzero integer is mathematically available after additional boundary data.
On an observed three-boundary, large `SL(2,C)` gauge components are indexed by
`pi_3(SL(2,C)) ~= Z`.  Selecting a component of winding `n` shifts the
normalized Chern--Simons transgression by `n`.  But neither the checked source,
the existing boundary presymplectic system nor classical edge BFV chooses
`n`.  The identity component supplies `n=0`.

Nor does an arbitrary interpolation between two connections quantize itself.
For `A_t=t theta` with the Maurer--Cartan relation `d theta=-theta^2`, the
normalized Chern--Simons value is

\[
q(t)=3t^2-2t^3.
\]

It obeys `q(0)=0`, `q(1)=1`, but `q(1/2)=1/2` and takes noninteger values in
the interior.  Integrality enters through the supplied endpoint or large-gauge
component, not through the local connection path.

There is a second Layer-0 burden before this can touch the four-dimensional
physics: `A0` is an ambient `P_H` connection, not automatically the observed
Lorentzian `SL(2,C)` chiral connection.  The tangential reduction/pullback and
its real invariant pairing still have to be owned by the action.  v0.150
already proved that the real pairing space is two-dimensional, leaving one
projective ratio after scale.

The current source-owned relative-selector route is therefore killed at the
claimed grade.  This is useful for the conditional build: it types the smallest
live external datum as a relative boundary component/integer together with an
action-owned chiral reduction and reality condition.  It does **not** kill
relative theories or the use of an explicit external datum.
