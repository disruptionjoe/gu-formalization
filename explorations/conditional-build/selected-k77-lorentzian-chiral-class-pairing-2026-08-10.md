actual observed chiral spin bundle. That identification is still natural, but

- If the observer spacetime is globally hyperbolic, it is diffeomorphic to

compact-support or boundary-transgression route remains live** and was already
foreshadowed by the boundary e-invariant program. The action must not be
restricted yet: first construct that relative class and show that the source

## Exact real-pairing calculation

linear invariance equation

```text
ad_x^T B + B ad_x = 0
```

for a symmetric `6 x 6` real matrix `B`. The solution space has dimension two.
Explicit generators are `Re Tr(XY)` and `Im Tr(XY)`. For
`B(a,b)=a B_Re+b B_Im`,

```text
det B(a,b) = -4(a^2+b^2)^3.
```

Thus every nonzero real combination is nondegenerate, and the real, imaginary
and mixed controls all have inertia `(3,3)`. After quotienting an overall scale,
one projective ratio remains. This is compatible with Lorentzian self-dual
