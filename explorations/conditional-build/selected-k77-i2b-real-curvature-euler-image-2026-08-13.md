# Selected K77 I2B real-curvature Euler-image theorem

## Outcome

The full pointwise real curvature-value route is closed at Euler grade on the
selected moving-`H_q`, zero-fermion branch. The grade-one residual carrier has
real dimension `392`. The exact residual-to-connection-Euler transfer has rank
`392`, hence is an isomorphism. The complete pointwise real `U(64,64)`
selected-Shiab curvature image has rank `364`; its Euler image also has rank
`364`. The fourteen-cell target Euler covector raises that image rank to `365`.

Therefore no pointwise real curvature value in the full `U(64,64)` parent can
cancel the I2B Euler covector. The smaller `U(32,32) x U(32,32)` block subgroup
cannot cancel it either. This is stronger than the predecessor residual-image
exclusion: varying the connection does not manufacture the missing real line,
because the residual-to-Euler map is invertible.

The unrestricted complex residual image does contain the target and therefore
provides the positive control. It is not an admissible real solution on this
branch.

## Layer 0

This theorem keeps four objects separate:

- two complex `C^(32,32)` carrier halves;
- their `U(32,32) x U(32,32)` block subgroup;
- the full `U(64,64)` parent;
- the independent real K77 connection tangent used by the Euler map.

It also distinguishes a pointwise curvature value from a derivative-dependent
source-connection jet. The theorem exhausts the former and says nothing terminal
about the latter.

V0.230 proves that reference connection, metric, section, Hodge, Shiab,
trace-frame and observer motion cannot cancel the independent `varpi/T` Euler
