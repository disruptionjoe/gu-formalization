# Post-N3 source-action/datum campaign rebase

## Decision

The existing scaffold should be adjusted, but not replaced.

The higher-order objective is also unchanged: construct or locate the
geometry that actually works. Weinstein's displayed action is a privileged
source comparator because it may reveal intended architecture. It is not an
authority that the campaign must preserve. Failure of Weinstein's
source-shaped branch is not failure of the geometry program; it is evidence
that narrows the next independently constructed geometric family.

The completed sequence

```text
N1 unified finite source-action/datum packet
  -> N2a actual-Sym2 bilinear/orbit screen
  -> N4a curvature-irrep screen
  -> N3 term-by-term variational emission map
```

remains useful and is not rerun. The adjustment is that the old immediate
continuation

```text
N3 -> N2b/N4b -> N5
```

is now premature.

N3 exposed a typed-current cancellation fork. The Vanchurin audit explains
how to finish the missing dependency, adjoint, musical, and
restriction/emission calculus. The Weinstein audit supplies a source-shaped
rival in which matter enters the total Euler residual rather than through a
separately assumed bridge, and in which the nonlinear eddy completion is
present before exactness is judged. N2b and N4b cannot quotient by “the Euler
ideal” until that action architecture is decided.

The campaign therefore inserts four construction waves before rejoining the
old N5--N10 sequence:

```text
completed N1/N2a/N4a/N3
          |
          v
RB1  dependency dictionary + connection-current musical
          |
          v
RB2  total-residual/current-bridge action shootout + exactness/Noether
          |
          v
RB3  moving symmetry + full-20 shared-spin-zero placement
          |
          v
RB4  moving defect calculus + N2b/N4b joint closure
          |
          v
RB5  unified quadratic five-leg solve
 -> RB6 nonlinear BV
 -> RB7 curved stationary gravity/DE/causality
 -> RB8 common Green/BFV domain and transport
 -> RB9 closed X4 physical Hessian/SM/anomaly
 -> RB10 actual twisted index and held-out tournament
```

This is a ten-wave next campaign, not a second ten-wave campaign running
beside the first. RB5--RB10 are the old N5--N10 with their input contract
revised. The original preregistration remains the provenance record.

## North-Star geometry continuation contract

A current candidate class is falsifiable. The larger directed search for a
working geometry does not stop merely because Weinstein's proposed
architecture, N1's first bridge, or another particular stratum dies.

Every killed branch must emit a **geometry return packet**:

1. the minimal failed map, equation set, symmetry condition, or analytic
   requirement;
2. the exact geometric locus on which it fails;
3. which current choice was structural and which was merely one candidate;
4. a bounded set of adjacent geometric mutation axes;
5. the smallest preregistered next family generated from those axes; and
6. the earliest RB wave that the new family must re-enter.

The initially admissible mutation axes are geometric rather than
target-fitting:

| mutation axis | examples of a bounded adjacent construction | required re-entry |
| --- | --- | --- |
| connection/action architecture | different native connection difference, parent, invariant pairing, or first-order functional class selected from a frozen natural basis | RB1 |
| soldering and symmetry | moving Clifford-plane orbit, explicit stabilizer geometry, or a different equivariant soldering representation already supported by the carrier | RB1 or RB3 |
| actual metric-fibre geometry | another classified \(\operatorname{Sym}^2T^*X\) orbit/Segre stratum or finite invariant hull, never the exterior ten by numerical analogy | RB3 |
| bulk/defect geometry | a different explicit lift, current, correspondence, or stratified action-domain construction | RB1 then RB4 |
| induced geometry and background | another source-generated stationary geometric family or finite equation-closed extension | RB4 or RB7 |
| end/domain/topology geometry | another declared end compactification, relative class, or symmetry-compatible domain family | RB8, with RB1 replay if the local current pairing changes |

This return mechanism is not permission for an unlimited rescue tower.
Before evaluating the failed target, each regeneration pass must freeze:

- which axes may move;
- the maximum number and dimension of adjacent families;
- the distance or complexity cost from the killed construction;
- the same five-leg constraint set and held-out wall; and
- the condition that sends a geometry back to RB1 rather than letting it
  inherit downstream results.

One minimal geometric mutation is preferred to simultaneous free changes.
If the minimal inconsistent set requires two coupled changes, they enter as
one explicitly charged joint branch. A new geometry does not inherit an old
Noether, BV, domain, spectrum, or index verdict merely because notation is
similar.

The campaign can therefore return:

```text
RB1/RB2 source-shaped branch dies
  -> preserve any independently constructed N1 survivor
  -> otherwise emit geometry return packet
  -> freeze bounded adjacent geometry
  -> re-enter RB1

RB3/RB4 placement or closure class dies
  -> emit symmetry/fibre/bulk-defect obstruction
  -> freeze bounded adjacent geometry
  -> re-enter RB1, RB3, or RB4 according to changed maps

RB5-RB10 current full packet dies
  -> current candidate class eliminated
  -> emit minimal cross-leg obstruction and next bounded geometry family
  -> re-enter at the earliest invalidated wave
```

This is North-Star pursuit, not refusal to accept a negative result. A
specific geometry can be killed decisively; what follows is a better
specified geometric experiment rather than hardening, rhetoric, or a
post-hoc coefficient repair.
