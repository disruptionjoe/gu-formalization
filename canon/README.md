# Canon

Stable public spine for the project. Files in this directory whose own
frontmatter says `status: canon` are safe to cite as current framing, but they
are not proof claims. Other native statuses in this directory remain staged,
active, superseded, or candidate material and are not made citable merely by
their path. The authoritative index and grades live in `../CANON.md`.

The root `RESEARCH-POSTURE.md` is the canonical statement of the project's current research philosophy:
the program optimizes for truth, using GU as a generative test case; the surviving (often GU-independent)
structure and the method are co-equal products; proof discipline and falsification standards remain intact.

Two orientation pointers:

- **Primary research question (2026-06-28):** the Firewall-Boundary Hypothesis
  (`firewall-boundary-hypothesis.md`) -- the current organizing falsification target (attack it, do not
  defend it).
- **Located-not-forced structural spine (GU-independent, internal tier):** a cluster of RESULTS files
  (`*-RESULTS.md`) promoted to canon; see the `CANON.md` tables. Canon here = citable spine, still internal
  tier (not externally replicated); the generation-count verdict stays OPEN and nothing derives three.
