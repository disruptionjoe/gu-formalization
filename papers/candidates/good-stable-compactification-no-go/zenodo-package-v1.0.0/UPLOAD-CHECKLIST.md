# Zenodo upload checklist

## Files

- [ ] Upload every file listed in `MANIFEST.sha256`.
- [ ] Confirm the PDF, TeX, Markdown, and source ZIP all say version 1.0.0.
- [ ] Confirm the PDF opens and contains rendered mathematics and tables.
- [ ] Select `compact-image-obstructions-sp32-32-v1.0.0.pdf` as the default
  preview.
- [ ] Confirm neither the ZIP nor the Markdown is the default preview.

## Metadata

- [ ] Paste the exact title from `METADATA.md`.
- [ ] Use creator `Joseph Hernandez` and affiliation `Independent Researcher`.
- [ ] Use resource type `Publication / Preprint`.
- [ ] Use version `1.0.0`, language `English`, and license `CC-BY-4.0`.
- [ ] Paste the full description from `METADATA.md`.
- [ ] Add `https://github.com/disruptionjoe/gu-formalization` as a related
  software resource with relation `Is supplemented by`.
- [ ] Do not infer or add an ORCID.
- [ ] Do not insert a DOI before Zenodo assigns one.

## Final pre-publication review

- [ ] Verify all required Zenodo fields are visibly populated after saving.
- [ ] Verify the repository URL is still present after saving.
- [ ] Verify the PDF is visibly marked as the default preview.
- [ ] Stop before the final Publish action unless Joseph explicitly approves
  that external action in the active session.
