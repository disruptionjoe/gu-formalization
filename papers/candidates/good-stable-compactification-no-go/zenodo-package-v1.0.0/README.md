# Zenodo release package - version 1.0.0

Title: *Compact-Image Obstructions for a Hyperbolic Grading in Sp(32,32):
Neutral, Grading-Even, and Extremal Order Parameters*

Author: Joseph Hernandez, Independent Researcher

This is the complete, pre-publication Zenodo package. It is bound to the exact
reviewed source revision recorded in `SOURCE-COMMIT.txt`. Building this package
does not authorize or perform a public deposit.

## Upload set

- `compact-image-obstructions-sp32-32-v1.0.0.pdf` - version of record and
  required default preview.
- `compact-image-obstructions-sp32-32-v1.0.0.tex` - standalone buildable LaTeX
  source used to produce the PDF.
- `compact-image-obstructions-sp32-32-v1.0.0.md` - editable Markdown source.
- `compact-image-obstructions-sp32-32-source-v1.0.0.zip` - standalone source,
  exact evidence, dependency locks, and review/reproduction records.
- `METADATA.md` and `CITATION.cff` - copy-ready deposit metadata.
- `ADVERSARIAL-SATURATION-RECEIPT-v1.0.0.md` - version-bound final hostile
  review disposition.
- `REPRODUCTION.md`, `VERIFICATION.md`, and `SOURCE-COMMIT.txt` - reproduction,
  release QA, and source provenance.
- `LICENSE-DOCS.md` and `LICENSE-CODE.md` - document and code licenses.
- `UPLOAD-CHECKLIST.md` and `MANIFEST.sha256` - deposit controls and exact
  payload checksums.

## Build the paper

With Tectonic installed:

```sh
tectonic compact-image-obstructions-sp32-32-v1.0.0.tex
```

The TeX source is standalone and does not require a separate bibliography
file. PDF build metadata may vary across toolchains even when rendered content
is equivalent.

## Mandatory Zenodo preview rule

Upload the complete set and explicitly select
`compact-image-obstructions-sp32-32-v1.0.0.pdf` as the default preview. The
Markdown, TeX, and ZIP files are public source and must never be the
reader-facing default preview.
